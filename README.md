پلات‌لی (Plotly) یک کتابخانه متن‌باز (Open Source) برای مصورسازی داده‌ها (Data Visualization) است که بر پایه کتابخانه جاوااسکریپت plotly.js ساخته شده. این کتابخانه برخلاف ابزارهای سنتی که خروجی ایستا (Static) تولید می‌کنند، نمودارهایی تعاملی (Interactive)، با کیفیت بالا و مبتنی بر وب ارائه می‌دهد.
